How this demo is assembled

CloudFormation creates a private S3 origin, CloudFront distribution, Cognito guest identity pool, CloudWatch RUM app monitor, SSM parameter, and a Lambda custom resource that publishes the instrumented pages.

The CI/CD option uses CodePipeline with a GitHub CodeStar connection and CodeBuild.

Built to explain the end-to-end RUM deployment flow.
